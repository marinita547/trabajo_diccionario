📖 Diccionario Técnico

Busca un término en inglés o español o filtra por categoría:

Programación

Algorithm / Algoritmo

Conjunto ordenado y finito de operaciones que permite hallar la solución de un problema o ejecutar una tarea informática.

📌 Ejemplo: "A sorting algorithm."
Programación

Bug / Error de Software

Fallo, error o defecto en un programa informático que produce un resultado no deseado o incorrecto.

📌 Ejemplo: "Debugging the application."
Programación

Framework / Marco de Trabajo

Estructura previa sobre la cual un desarrollador puede construir aplicaciones sin tener que empezar desde cero.

📌 Ejemplo: "React is a JS library/framework."
Redes y Seguridad

Firewall / Cortafuegos

Sistema de seguridad de red que monitorea y controla el tráfico entrante y saliente según reglas predefinidas.

📌 Ejemplo: "Blocked by the network firewall."
Redes y Seguridad

Bandwidth / Ancho de Banda

Cantidad máxima de datos transmitidos a través de una conexión de red en un periodo de tiempo determinado.

📌 Ejemplo: "High bandwidth connection."
Hardware & Cloud

Cloud Computing / Computación en la Nube

Entrega de servicios de computación (servidores, almacenamiento, bases de datos) a través de Internet.

📌 Ejemplo: "Deployed on AWS Cloud."
