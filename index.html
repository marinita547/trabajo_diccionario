Diccionario de Términos Informáticos

Escribe en el buscador o selecciona una categoría para filtrar:

Programación

Algorithm / Algoritmo

Conjunto de instrucciones ordenadas y finitas que permiten resolver un problema o realizar una tarea.

📌 Uso: "The search algorithm ranks results fast."
Programación

API / Interfaz de Programación

Conjunto de reglas que permite que dos aplicaciones de software se comuniquen entre sí.

📌 Uso: "Fetching user data via REST API."
Programación

Bug / Error de Software

Fallo o defecto en el código informático que causa resultados inesperados o errores en el sistema.

📌 Uso: "Developers fixed the login bug."
Programación

Framework / Marco de Trabajo

Estructura base de software sobre la cual los programadores construyen aplicaciones más rápido.

📌 Uso: "React is a popular JavaScript framework."
Programación

Backend / Lógica del Servidor

Capa interna de un sitio web que gestiona bases de datos, servidores y lógica de negocio.

📌 Uso: "Python is widely used in backend code."
Programación

Frontend / Interfaz de Usuario

Parte visual e interactiva de una aplicación con la que interactúa directamente el usuario.

📌 Uso: "HTML, CSS and JS make up the frontend."
Redes & Ciberseguridad

Firewall / Cortafuegos

Sistema de seguridad que monitorea y bloquea el tráfico de red no autorizado según reglas.

📌 Uso: "The firewall blocked external attacks."
Redes & Ciberseguridad

Phishing / Suplantación de Identidad

Técnica engañosa para robar información confidencial como contraseñas o tarjetas de crédito.

📌 Uso: "Beware of email phishing scams."
Redes & Ciberseguridad

Bandwidth / Ancho de Banda

Capacidad máxima de datos que puede transmitirse a través de una red en un tiempo determinado.

📌 Uso: "High bandwidth enables 4K streaming."
Hardware & Cloud

Cloud Computing / Computación en la Nube

Servicios de cómputo y almacenamiento provistos directamente a través de Internet.

📌 Uso: "Our files are backed up on the cloud."
Hardware & Cloud

RAM / Memoria de Acceso Aleatorio

Memoria ultrarrápida del sistema utilizada para ejecutar programas activos de forma temporal.

📌 Uso: "16GB RAM is great for multitasking."
Inteligencia Artificial

Machine Learning / Aprendizaje Automático

Rama de la IA que permite a los sistemas aprender y mejorar automáticamente a partir de datos.

📌 Uso: "AI uses machine learning for predictions."

🐛 ¿Por qué se llama "Bug"?

En 1947, los ingenieros encontraron una polilla real atascada en la computadora Mark II. De ahí nació el término informático para referirse a los errores.
